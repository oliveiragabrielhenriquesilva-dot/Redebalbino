Construtor do fluxo de atendimento

Monte uma árvore de triagem com botões, listas ou texto por nome. O Balbino Chat não usa menu numérico como modo alternativo.

WhatsApp interativo

Modo Automático: até 3 escolhas usa botões rápidos; com 4 ou mais opções usa lista para exibir todas as escolhas. Mesmo que “Botões rápidos” esteja selecionado, uma etapa com mais de 3 opções será convertida automaticamente em lista para não cortar opções. Se o WhatsApp não aceitar o formato, o modo alternativo usa os nomes das opções em texto — nunca “1, 2, 3”. Você também pode forçar Botões, Lista ou Texto em cada etapa.
Etapas do fluxo
“Opção exibida ao contato” é o texto que aparece no WhatsApp. “Valor salvo no CRM” é apenas interno. A mensagem após a escolha é opcional e pode ser usada antes da próxima etapa ou como resposta final.

Integração com o sistema de matrículas

O sistema de matrículas envia os itens para o Balbino Chat por uma API local. As mensagens saem pela conexão WhatsApp selecionada.
